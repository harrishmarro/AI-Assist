# Python Voice Assistant

An early Python learning project that accepts voice commands and can play music,
report the time and weather, summarize Wikipedia topics, and tell jokes.

## Configuration

The weather command requires an OpenWeather API key. Set it in your shell before
starting the assistant:

```bash
export OPENWEATHER_API_KEY="your-key"
python "AI Recoginition.py"
```

Never commit API keys or other credentials to this repository.

## Project status

This is an archived learning project. It is retained to show early experimentation
with speech recognition and third-party APIs; it is not production-ready.
